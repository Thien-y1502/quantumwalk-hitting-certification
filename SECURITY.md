# Security policy

`qwcert` is a numerical research package. It does not handle credentials or network input, but
reports are still welcome, for example about unsafe file handling in the scripts or a pinned
dependency with a known vulnerability.

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/Thien-y1502/quantumwalk-hitting-certification/security/advisories/new)
instead of a public issue. We aim to acknowledge reports within 7 days.
