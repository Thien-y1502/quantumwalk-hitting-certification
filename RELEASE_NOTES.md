# Release v0.1.0

Initial public release of the reference implementation and reproducibility package.

Included in this release:

- 375 graph-mark-policy evaluations across seven graph families;
- five floor choices and 1,875 floating-point certificate runs;
- marked-rooted, hybrid, multi-forest, and reference Dirichlet comparisons;
- 21 finite cubic hard/easy target instances;
- six selected exact-rational post-validation cases;
- 14 proposal-degradation stress cases;
- fixed-proposal ablation;
- deterministic configuration, raw outputs, tables, figures, tests, environment metadata, and checksums.
